# 🎓 Graduation Invitation | Thiệp Mời Tốt Nghiệp

Dự án thiệp mời tốt nghiệp với thiệp 3D lật tương tác, nhạc nền, pháo hoa hạt canvas, và tra cứu tên khách mời tự động, xây dựng trên nền tảng **Angular 20 Standalone Application**.

## 🚀 Triển khai (Deploy to GitHub Pages)
- Chạy file: `deploy-github-pages.bat`
- Hoặc chạy lệnh:
  ```bash
  npm run build -- --configuration=production --base-href="/Graduation-Invitation/"
  ```
